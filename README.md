# BookIdle — site

Página de apresentação do [BookIdle](https://github.com/PatrickKenji/BookIdle-releases), gerenciador de contas e ferramentas
para o pokeidle.io (gratuito e de código aberto).

Site estático, sem build: `index.html` + `fonts/` + `img/`. Para ver localmente:

```bash
python -m http.server 8765   # e abra http://localhost:8765
```

Na Vercel: importe este repositório como projeto **Other**, sem comando de build e com a raiz como diretório de saída.

As fontes (Press Start 2P e Space Grotesk) são licenciadas sob a OFL; os textos de licença estão em `fonts/`.
