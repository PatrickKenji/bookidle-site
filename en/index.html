Your idle-game accounts, in one place.

BookIdle opens each account in an isolated browser, arranges the windows and looks after memory. For some games it goes further, with tools made to measure.

Built for people who play with several accounts.

One profile per game

Each game gets its own profile, with its own account list, account limit and windows.

Optional password vault

Encrypted on your computer, with your Windows user or a master password. Automatic login is optional too, and on Google accounts the app never types your password.

Light and under control

  • Shows each account's memory and reloads the one that goes over the limit you set.
  • Blocks ads and trackers by domain list.
  • Goes to the Windows tray and can start along with it.

Updates itself

The app checks for new versions when it opens and every hour, tells you, and updates with one click, downloading only what changed.

Tools made to measure for certain games.

Beyond the basics, some games get features made for them. We started with one, and the next ones come from what players need.

  • Market sniperBuys in the background whatever matches your rules, with a shiny, P5 and rating radar, and a balance reserve that is never spent.

FAQ.

Is it official? Are you affiliated with any game?

No. BookIdle is an independent project, with no affiliation with pokeidle.io or any other game you open in it, and no connection to TopIdle, Twitch, Nintendo or The Pokémon Company. All trademarks belong to their respective owners.

Can I get banned for using it?

Each game has its own rules, and you are responsible for following them, including the limit of accounts per person. On pokeidle.io, the only game with automatic tools today, the game allows automation that follows the same rules as someone playing by hand and limits you to 4 accounts per person, across all computers and networks. Read the terms of the game you use.

Does the pokeidle.io sniper spend real coins?

Yes, it spends the game's coins and gems. Start with small rules and a high balance reserve, and watch the event feed. A purchase that has been made is not undone by the game.

Does it work with other idle games?

Yes: BookIdle opens any browser game in separate profiles and already works as a multi-account manager. The custom tools (vote, hunts, sniper, Twitch) exist today only for pokeidle.io, and new ones are built as needed. Tell us which game you want.

Does it cost anything? How can I help?

It is free. If you want to help, the Support button leads to the support page. It is not required and nothing is locked for people who do not support.
